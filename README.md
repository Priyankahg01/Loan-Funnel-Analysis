# Loan Funnel Analysis

## 📌 Project Overview

This project analyzes the loan application process using data analytics to understand the complete loan funnel, from application to approval and loan processing.

The analysis focuses on identifying conversion rates, approval patterns, loan processing performance, customer characteristics, and repayment behavior.

## 🎯 Objectives

- Analyze the loan application funnel from application to processing.
- Measure loan approval and processing rates.
- Identify trends based on customer income level and credit score.
- Analyze loan performance across different loan products.
- Evaluate customer acquisition cost and loan amounts.
- Analyze repayment performance.
- Identify key insights that can help improve the loan process.

## 🛠️ Tools & Technologies

- Tableau – Dashboard and data visualization
- SQL – Data analysis and querying
- Python – Data cleaning and analysis
- Microsoft Excel – Data preparation
- GitHub – Project documentation and version control

## 📊 Dashboard

The Tableau dashboard provides an interactive view of the loan funnel and includes:

- Key Performance Indicators (KPI's)
- Loan Funnel Analysis
- Processing Rate by Product Type
- Processing Rate by Credit Score
- Processing Rate by Income Level
- Processing Rate by Sales Representative
- Call Outcome Distribution
- Call Duration Analysis
- Repayment Analysis
